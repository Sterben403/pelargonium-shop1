# Pelargonium Shop в Тильде

Как устроено:

```
 Тильда (сайт для покупателей)                     Наш сервер (backend/)                PostgreSQL
 ├─ шапка, обложка, «Уход», «Доставка» — блоки Тильды
 ├─ блок T123 «HTML-код» ── виджет каталога ──────▶ /api/varieties, /api/orders ───▶ сорта, заказы
 └─ (по желанию) форма Тильды ── вебхук ──────────▶ /api/tilda/webhook ─────────────▶ заказы
                                                    /admin — кабинет владелицы
```

Тильда отвечает за внешний вид и тексты, наш сервер — за каталог, наличие, заказы и кабинет владелицы.
Владелица меняет цены, наличие и фото в `/admin`, и сайт в Тильде показывает это сразу, без переопубликации.

## 0. Что нужно заранее

1. **Платный тариф Тильды (Personal).** Блок T123 «HTML-код» и приём заявок через вебхук
   на бесплатном тарифе недоступны. В бизнес-кейсе (ЛЗ-3) тариф Personal уже заложен: 500 ₽/мес.
2. **Сервер с адресом в интернете по HTTPS.** Сайт Тильды открывается у покупателей,
   и их браузеры не могут обратиться к `localhost` на вашем компьютере. Варианты:
   - **для защиты / демонстрации** — временный туннель, без покупки сервера (раздел 4);
   - **для реального запуска** — VPS (в бизнес-кейсе: Hoster.kz, 3 100 ₸/мес) + домен.

Пока сервера в интернете нет, всё можно показать локально: **http://localhost:8010/demo** —
это страница, собранная так же, как будет в Тильде.

## 1. Страница в Тильде

Создайте страницу и добавьте блоки по порядку:

| Блок Тильды | Что поставить |
|---|---|
| Меню (ME…) | логотип «Pelargonium Shop», ссылки `#catalog`, `#care`, `#delivery` |
| Обложка (CR…) | заголовок «Сортовые пеларгонии с домашнего подоконника», кнопка «Смотреть каталог» → `#catalog` |
| Заголовок (TL…) | «Каталог сортов», якорь блока: `catalog` |
| **T123 «HTML-код»** (категория «Другое») | код из раздела 2 |
| Преимущества / карточки (FR…) | «Памятка по уходу», якорь `care` — тексты ниже |
| Карточки (FR…) | «Получение и оплата», якорь `delivery` |
| Подвал (FT…) | © 2026 Pelargonium Shop · фото сортов — Wikimedia Commons |

Тексты для «Ухода» и «Доставки» на трёх языках лежат в `backend/app/static/i18n.json`
(ключи `tips`, `pickupText`, `courierText`, `payText`) — можно копировать оттуда.

## 2. Код для блока T123

Замените `API_ADDRESS` на адрес сервера (например, `https://pelargonium-api.kz`
или адрес туннеля из раздела 4):

```html
<div id="pelargonium-catalog"></div>
<script src="https://API_ADDRESS/static/widget/pelargonium.js"></script>
```

Виджет сам рисует фильтры, карточки с фото, окно сорта с памяткой по уходу, корзину и форму заказа,
и переключает RU / KZ / EN.

Дополнительные настройки (атрибуты тега `<script>`):

| Атрибут | Значение |
|---|---|
| `data-lang="kk"` | язык по умолчанию: `ru`, `kk` или `en` |
| `data-lang-switch="false"` | спрятать переключатель языка — если в Тильде отдельные страницы `/ru`, `/kz`, `/en` |

Например, для казахской версии страницы:

```html
<div id="pelargonium-catalog"></div>
<script src="https://API_ADDRESS/static/widget/pelargonium.js" data-lang="kk" data-lang-switch="false"></script>
```

> В редакторе Тильды HTML-блоки не выполняются — виджет видно в режиме **«Предпросмотр»** и на опубликованной странице.

## 3. (По желанию) обычная форма Тильды → заказы в базу

Если хочется использовать стандартную форму Тильды (например, «Быстрый заказ» без корзины):

1. **Настройки сайта → Формы → Webhook.** Адрес:
   `https://API_ADDRESS/api/tilda/webhook?token=ВАШ_TILDA_WEBHOOK_TOKEN`
   (токен — из `backend/.env`, параметр `TILDA_WEBHOOK_TOKEN`). Тильда отправит проверочный
   запрос — сервер ответит `ok`, и подключение сохранится.
2. В блоке формы: **Контент → Сервисы приёма данных** → отметьте Webhook.
3. Названия полей (колонка «Переменная» в настройках формы):

| Переменная | Что это | Пример |
|---|---|---|
| `name` | имя покупателя | Аяулым |
| `phone` | телефон | +7 701 123 45 67 |
| `variety` | название сорта, как в каталоге | Lord Bute |
| `qty` | количество | 1 |
| `delivery` | «Самовывоз» или «Курьер» | Курьер |
| `address` | адрес (для курьера) | ул. Абая 10 |
| `comment` | комментарий | позвонить после 18:00 |

Корзина Тильды (ST100 / T706) тоже поддерживается: сервер читает список товаров из поля `payment`,
если названия товаров в Тильде совпадают с названиями сортов.
Заказы с формы попадают в тот же реестр, с пометкой `[Tilda]` в комментарии.

Совет: в форме оставьте и **уведомление на почту** — если сорт с таким названием не найдётся,
заявка всё равно не потеряется.

## 4. Показать на защите без своего сервера (туннель)

1. Запустите базу и сервер (см. README.md).
2. Скачайте `cloudflared` с официального сайта Cloudflare и выполните:
   ```bash
   cloudflared tunnel --url http://localhost:8010
   ```
3. Он выдаст адрес вида `https://something-random.trycloudflare.com` — подставьте его вместо
   `API_ADDRESS` в блоке T123 и опубликуйте страницу.
4. Кабинет владелицы: `https://something-random.trycloudflare.com/admin`.

Туннель работает, пока открыт терминал; адрес меняется при каждом запуске.

## 5. Свой домен в Тильде

Страницы на `*.tilda.ws` сервер пускает автоматически. Если подключите свой домен
(например, `pelargonium.kz`), добавьте его в `backend/.env`:

```
CORS_ORIGINS=https://pelargonium.kz,https://www.pelargonium.kz
```

и перезапустите сервер.

## 6. Перед реальным запуском

- `backend/.env`: поменять `ADMIN_PASSWORD`, `SECRET_KEY`, `TILDA_WEBHOOK_TOKEN`, пароль PostgreSQL.
- Сервер — только по HTTPS (Тильда работает по HTTPS, и браузер не даст ей обращаться к HTTP).
- Делать резервные копии базы: `docker exec pelargonium-db pg_dump -U pelargonium pelargonium > backup.sql`.
