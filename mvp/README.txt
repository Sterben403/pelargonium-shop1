Pelargonium Shop — MVP
======================

Как запустить
-------------
Откройте index.html двойным кликом в любом браузере (Chrome, Edge, Opera, Firefox).
Сервер и установка не нужны. Для фото сортов нужен интернет
(без интернета вместо фото показываются рисунки).

Что есть
--------
- Каталог из 15 сортов без регистрации: фото, цена, наличие, описание.
- Фильтры: поиск по названию, тип цветка, цвет, «только в наличии», сортировка.
- Памятка по уходу (общая и для каждого типа), условия получения и оплаты.
- Корзина и заказ: имя, телефон, самовывоз / курьер, проверка полей,
  номер заказа (PS-1001, PS-1002…).
- Языки: RU / KZ / EN (переключатель в шапке).
- Кабинет владелицы (пункт меню «Владелице»):
    * реестр заказов, фильтр и смена статуса, звонок по клику на телефон;
    * редактирование цены, наличия и описания;
    * добавление новых сортов с фото, замена фото, удаление сортов;
    * инструкция для владелицы.

Демо-пароль кабинета: pelargonium2026
(в коде: константа ADMIN_PASSWORD в index.html)

Ограничения MVP
---------------
- Данные (заказы, новые сорта, изменения) хранятся в браузере (localStorage),
  где их ввели. Они не общие для разных устройств — для этого нужен сервер с базой.
- Пароль проверяется в браузере — это защита только для демонстрации.
- Онлайн-оплата и автоматический расчёт доставки не входят в MVP.
